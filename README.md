# Cell Stage — прототип клеточного этапа Spore

Играть: https://etopaha.github.io/spore-clone/

Браузерная игра на Three.js из примитивов: клетка плавает, ест, растёт, её едят крупные.

Управление: WASD или зажатая ЛКМ — плыть, пробел — рывок, Q — яд, E — редактор клетки, Esc — меню.

Здесь только собранный сайт (сборка из исходников 07a5057).
